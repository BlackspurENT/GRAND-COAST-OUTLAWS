# Grand Coast Outlaws — Development Status

**Studio:** Blackspur Entertainment  
**Project:** Grand Coast Outlaws (GCO)  
**Technology:** Unreal Engine 5 / C++  
**Stage:** Early development — internal prototype

> This document describes internal development milestones, not a publicly released game or a production-ready dedicated server.

## Reported internal progress

Based on development notes last reviewed on 6 October 2026:

- An Unreal Engine Development Editor build was reported as successful.
- Initial C++ gameplay and architecture foundations span seven Unreal modules.
- Basic coastal district and main menu maps were generated in the editor.
- A prototype menu scene was rendered and reviewed.
- Limited multiplayer role and movement tests passed in a two-player, single-process PIE listen-server setup.
- Internal Python and native C++ verification tools were exercised.

These are **project-reported engineering results**. They do not establish production-game readiness, measured scalability or an externally hosted dedicated-server build.

## Current development priorities

1. Create a small, coherent playable city district.
2. Validate real client/server packaging and an Unreal dedicated-server executable.
3. Record reproducible multiplayer connection and replication tests.
4. Measure CPU, RAM, network performance and deployment behavior.
5. Capture and approve in-engine visuals for public presentation.

## Planned features

An expanded coastal metropolis; vehicles; police and criminal gameplay; heists and wanted systems; persistent multiplayer systems; final character, world and interface art.

These are development goals **not claims of completed functionality**.
