# GCO — Public Development Roadmap

Updated 12 October 2026. This roadmap is a plan, not a public release commitment.

| Phase | Deliverable | Current status |
| --- | --- | --- |
| 0. Unreal foundation | Unreal Engine editor build, C++ modules, initial menu and map blockout | Initial internal checks reported |
| 1. Playable multiplayer prototype | Independently launched clients, role selection, small playable area and one completed gameplay objective | In development |
| 2. Dedicated server pilot | Packaged standalone server, remote clients, repeatable deploy instructions | Not yet validated |
| 3. Gameplay vertical slice | Vehicles, first heist, police response, wanted/bounty loop and economy test | Planned |
| 4. Expansion | Additional districts, content production, world streaming and performance profiling | Planned |
| 5. External access | Broader testing, distribution preparation and public announcements | Planned |

## Required evidence before a milestone is marked complete

**Playable prototype:** a working build, two independent clients, test logs, a complete playable objective, and a reviewed in-engine video or screenshot.

**Dedicated server:** verified server executable, documented dependencies and launch parameters, remote connection evidence, and CPU/memory/network results under a specified test load.

**Gameplay vertical slice:** end-to-end functionality beyond menu items, placeholder geometry or isolated unit tests.

Only report features as completed when the supporting test or demonstration exists. A successful editor compilation is not proof of a finished game. No public release date has been announced.
