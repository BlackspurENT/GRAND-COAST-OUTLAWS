# Grand Coast Outlaws — Partner Overview

**Blackspur Entertainment** · Independent Unreal Engine 5 / C++ project  
**Status:** early prototype · **Public release:** not announced

## About the project

Grand Coast Outlaws (GCO) aims to combine a large fictional coastal setting with online police and criminal experiences, vehicle gameplay and repeatable cooperative or competitive objectives. The scope is ambitious; the production plan is to validate a **small vertical slice** before expanding the world.

## What exists so far

Internal records describe a compiling Unreal Editor foundation, a set of early C++ modules, blockout maps, prototype in-engine menu, and narrowly scoped local multiplayer replication tests.

These results are promising **development steps**, not yet a finished game, externally demonstrated network service or production dedicated-server package.

## What we are seeking

GCO welcomes introductory discussions with organizations offering:

- Dedicated game-server hosting and deployment feedback once a working server package exists.
- Temporary development/test infrastructure with transparent trial conditions.
- Guidance on Linux/Windows server packaging, monitoring, scaling and security.
- Advice or structured feedback on profiling a repeatable small multiplayer demo.

The project is not asking potential partners to assume that a prototype will necessarily become a commercial success. Any sponsorship, pricing, credits or marketing collaboration must be agreed separately.

## Suggested phased collaboration

**Phase 1 — Technical fit:** compare operating-system support, deployment format, network model and trial limits.

**Phase 2 — Contained pilot:** supply a validated server artifact; launch a bounded test; document resource usage and connectivity.

**Phase 3 — Results review:** share a concise technical report, assess cost and scaling, and decide whether ongoing collaboration is appropriate.
