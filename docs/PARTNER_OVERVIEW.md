## Project brief

Grand Coast Outlaws (GCO) is an independent open-world multiplayer action project in early Unreal Engine 5 / C++ development. Its creative direction brings police operations, criminal crews and vehicle pursuits into a fictional coastal metropolis.

The near-term production objective is deliberately focused: build and demonstrate one coherent multiplayer district and gameplay loop before expanding the world.

| Technology | Unreal Engine 5 / C++ |

| Reported networking checks | Limited two-player, single-process editor listen-server tests |

## Where a conversation is useful

We welcome discussions with infrastructure providers and technical organizations about:

- **Deployment fit:** operating systems, Unreal packaging, runtime dependencies and network requirements.
- **A bounded infrastructure pilot:** temporary development or test capacity, agreed limits and transparent commercial conditions.
- **Measurement and diagnostics:** repeatable connectivity checks, CPU and memory profiling, bandwidth measurements and useful logs.
- **Technical feedback:** practical review of the first multiplayer deployment and its next engineering steps.

Any sponsorship, credits, pricing or promotional activity would be discussed and agreed separately. No infrastructure provider is represented as a confirmed sponsor or production host.

## A practical collaboration path

| Step | Shared objective | Reviewable output |
| --- | --- | --- |
| 1. Technical fit | Compare hosting requirements, supported formats and trial conditions | A short compatibility and scope note |
| 2. Pilot readiness | Validate the server package and independent client connections | Working artifact, launch instructions and test evidence |
| 3. Contained pilot | Run a defined test with agreed resources and duration | Connectivity, stability and resource measurements |
| 4. Results review | Assess the findings and possible next steps | A concise technical report and a follow-up decision |

The pilot begins after a real server package passes the readiness checks. The [hosting evaluation brief](HOSTING_EVALUATION.md) describes each gate in more detail.
