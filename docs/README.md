## How to read the project record

**Current status** describes reported prototype work and open engineering gates. **Vision** and **roadmap** describe intended work. **Concept artwork** communicates visual direction; it is not captured gameplay.

The public repository is a showcase and documentation hub. Unreal source, internal maps and unreleased production assets are maintained separately. No public playable build or release date has been announced.
