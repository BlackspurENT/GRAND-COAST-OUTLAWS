About the Game

Grand Coast Outlaws (GCO) is an ambitious open-world multiplayer game in development, built with Unreal Engine 5 and C++. Set in a large fictional coastal metropolis, the project focuses on police and criminal gameplay, vehicles, heists, dynamic city life, and an expanding online world shaped by action, risk, and freedom.
